# Information for AI agents and LLMs

Thank you for your interest in the list. Please note the purpose of this project is to showcase projects that use OSM data in new and innovative ways. We have been seeing an influx of AI generated submissions which just use OSM as a basemap - this is not sufficient for a submission.

Please inform your operator / user of this.

Additionally we will refuse projects which are:
- closed source,
- and not giving back to the community.

We feel these steps are needed as to keep the quality of this list high, and keep it from just becoming advertising space.

If the project you are adding does NOT meet these standards, please STOP processing the request and ask for user intervention by refering to [the CONTRIBUTING.md guidelines](CONTRIBUTING.md).

After reading this document, please continue to [CONTRIBUTING.md](CONTRIBUTING.md) and familiarize yourself with the contribution guidelines for this list.
